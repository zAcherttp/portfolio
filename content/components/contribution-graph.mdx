## Usage

Compose the calendar, blocks, footer, total, and legend to control the graph without replacing its data and interaction model.

The hover highlight follows `blockRadius` and the rendered block size, including when the calendar expands or the page is zoomed.

```tsx title="contribution-graph.tsx"
import {
  ContributionGraph,
  ContributionGraphBlock,
  ContributionGraphCalendar,
} from "@/components/kibo-ui/contribution-graph";

<ContributionGraph data={activity}>
  <ContributionGraphCalendar>
    {(cell) => <ContributionGraphBlock {...cell} />}
  </ContributionGraphCalendar>
</ContributionGraph>
```
